# FearSensiZ

Phone-wise sensitivity settings for **Free Fire India** and **Free Fire MAX**.
Ek single self-contained HTML file — koi build step nahi, koi server nahi.

## Live

- Render: https://fearsensiz.onrender.com
- GitHub Pages: https://sahilalamx07-afk.github.io/FearSensiZ/

## Render par deploy (free static site)

1. render.com par GitHub se sign up karo (card nahi chahiye).
2. Dashboard -> **New +** -> **Static Site**.
3. Repo `sahilalamx07-afk/FearSensiZ` connect karo.
4. Branch: `main` · Build Command: *(khali chhodo)* · Publish Directory: `.`
5. **Create Static Site** dabao. Bas — 1 minute me live.

`render.yaml` blueprint bhi hai: **New +** -> **Blueprint** -> repo chuno -> **Apply**.

## Features

- 349 phone models ka database (screen size, refresh rate, chipset tier)
- List me na ho to naam se specs estimate ho jaati hain
- Result panel me specs manually correct kar sakte ho, sens live update hoti hai
- Copy / .txt / .png export — YouTube subscribe ke baad unlock
